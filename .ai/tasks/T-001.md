## Goal
A working, demoable version of the SEC WhatsApp AI counsellor covering every BRD module,
running on free/open-source infra (Render + Postgres), so management can see the real
flow (QR → WhatsApp/web chat → consent → journey fork → progressive profiling → AI
counselling with RAG + routed grounding → eligibility → DIY handoff → agent takeover →
admin reporting) without needing AWS, Bedrock, DIY, or Processio to exist.
